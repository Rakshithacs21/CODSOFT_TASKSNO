# Task 1 - To-Do List

## Description
A Python To-Do List application that helps users manage their daily tasks. Both console and GUI versions are included.

## Files
- `todo_list.py` - Console version
- `todo_gui.py` - GUI version

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks

## Technologies Used
- Python
- CustomTkinter (GUI version)

# Task 3 - Password Generator

## Description
A password generator that creates secure passwords. Both console and GUI versions are included.

## Files
- `password_generator.py` - Console version
- `gui_password_generator.py` - GUI version

## Features
- Generate weak, medium, and strong passwords
- Custom password length
- Copy password to clipboard (GUI)
- Save generated passwords

## Technologies Used
- Python
- CustomTkinter (GUI version)
- Pyperclip
